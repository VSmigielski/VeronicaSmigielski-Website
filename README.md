# veronicasmigielski.com

My personal portfolio, rebuilt in 2026 with Vite, React and TypeScript.

```bash
npm install
npm run dev     # local dev server
npm run build   # production build in dist/
```

Project content lives in `src/data.ts`; styles in `src/index.css`. Netlify builds with `npm run build` and serves `dist/`.

The original 2021 static HTML site is in this repo's git history.
